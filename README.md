# 🇮🇳 India Job Market Dashboard

A data-driven dashboard analyzing **India’s job market trends**, including job demand, salaries, experience levels, cities, and hiring companies.  
This project provides actionable insights for **job seekers, analysts, and recruiters** using interactive visualizations.

## 🔍 Key Insights

- **Total Jobs Analyzed:** 30,000+
- **Average Salary:** ₹1.29M per year
- **Top Hiring City:** Bangalore
- **Most In-Demand Role:** Cybersecurity
- **Highest Paying Roles:**
  - Cloud Architect
  - Product Manager
  - Machine Learning Engineer

---

## 📈 Analysis Highlights

### 🏙️ Job Distribution
- Strong hiring concentration in metro cities like **Bangalore, Hyderabad, Mumbai, and Delhi**
- Indicates tech and enterprise-driven demand

### 💼 Experience vs Remote Work
- Entry and mid-level roles show a **balanced mix of remote and on-site jobs**
- Senior roles lean slightly more towards **on-site opportunities**

### 💰 Salary Trends (2016–2024)
- Steady long-term salary growth
- Minor fluctuations but consistent upward trend overall

### 🏢 Hiring by Company
- Major recruiters include:
  - Adani Enterprises
  - Capgemini India
  - Paytm
  - Hindustan Unilever
  - State Bank of India
